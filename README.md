# Data Analytics & Exploratory Data Analysis (EDA) Projects 📊

This repository contains a collection of practical exercises, projects, and pipeline implementations developed during my Data Science Specialization at UFOP and the Google Data Analytics Professional Certification. 

The primary focus of these projects is applying statistical learning, data manipulation, and explanatory analysis to solve real-world industrial and business challenges.

---

## 🚀 Projects & Key Implementations

### 1. Exploratory Data Analysis (EDA) & Data Cleaning
- **Objective:** Ingesting raw multi-source business data, handling missing values, standardizing typologies, and treating outliers.
- **Tech Stack:** Python (`pandas`, `numpy`), Jupyter Notebooks.
- **Business Focus:** Ensuring high data quality and governance structures before analytical deployment.

### 2. Business Performance & Metrics Modeling
- **Objective:** Developing structured scripts to calculate core business KPIs (e.g., Average Order Value (AOV), Revenue Allocation, Retention Trends) using transactional e-commerce matrices.
- **Tech Stack:** Python (`pandas`, `matplotlib`, `seaborn`), Structured Queries (SQL).
- **Business Focus:** Transforming raw historical rows into interactive executive data summaries.

---

## 🛠️ Toolbelt & Technologies
- **Languages:** Python (3.x), SQL
- **Libraries & Frameworks:** Pandas, NumPy, Matplotlib, Seaborn
- **Development Environments:** Google Colab, Jupyter Notebook, Git/GitHub

## 📈 Key Methodology Checklist
1. **Data Ingestion:** Reading data configurations smoothly while tracking missing indices.

3. **Actionable Summaries:** Compiling categorical results to drive strategic and logical operational choices.
